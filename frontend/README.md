# Stock.co - Sistem Manajemen Stok Gudang

## Deskripsi

Stock.co merupakan aplikasi berbasis web untuk membantu proses pengelolaan
stok barang pada gudang. Aplikasi ini menyediakan beberapa fitur seperti
dashboard, analisis stok, SKU database, stok masuk, stok keluar, riwayat stok,
dan data pemasok.

Aplikasi ini dibuat sebagai tugas UTS Frontend Development.

---

## Teknologi yang Digunakan

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Node.js
- npm

---

## Fitur

- Dashboard
- Analisis Stok
- Aktivitas Terbaru
- SKU Database
- Stok Masuk
- Stok Keluar
- Riwayat Stok
- Data Pemasok
- Profil Pengguna
